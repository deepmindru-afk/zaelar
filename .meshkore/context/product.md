# Product

**Who**: people who want one agent to run their day instead of fifty apps — launched in English first, the product
speaks English and Spanish. One owner per agent; family sharing is future.

**Positioning**: not «another AI assistant» — a **personal operating system**: you talk, it acts, and the screen is
a canvas of apps (widgets) that it opens, drives and can write for you. The agent is also a citizen of the
**MeshKore network** (our own project): it asks other agents for what it cannot do itself.

**Value**:
- Voice-first: answers in under a second, can be interrupted and corrected, remembers across sessions
- Canvas of widgets: built-ins plus generated ones («describe it and it writes the widget», beta)
- Own brain, own memory: Colmena (`nucleo/`) + one SQLite file — the memory is yours
- Proactive: reminders and agenda alerts that fire without being asked
- Runs errands: messaging connectors, its own browser (beta), live agents on the mesh
- Trust you can check: the engine is public (fair-code, Sustainable Use License), self-host for free, or use the
  hosted version where every account gets its own isolated machine

**Anti-product**:
- NOT a thin wrapper over one chatbot — own brain, own memory, models chosen per piece
- NOT open source in the OSI sense — fair-code: use it yourself freely, commercial resale is not allowed
- NOT a general developer IDE — widgets are generated by exactly one scoped agent per task
- NOT a reasoning-on-every-turn system — the voice path is non-reasoning by hard rule
- NOT a shared multi-tenant process — the hosted version runs one isolated machine per account
